# CyberNetrix Dark

A cozy night-mode look for Claude that fuses cyber security and AI: muted blue-black
surfaces tuned for long sessions, neon cyan/teal highlights, electric violet for neural
accents, and a soft red kept for alerts. Behind the chat, a dim neural network drifts in
two parallax layers over faint circuit traces while signals pulse between nodes, under
frosted glass panels. Motion stops when the OS asks for reduced motion.

Drawn by the Claude desktop and mobile apps; terminals and editors keep their own look.

## Files

- `hooks/register.tsx`: the palette, frosted glass and backdrop hook.
- `hooks/scene.ts`: the animated backdrop SVG, generated by `scripts/gen-scene.mjs`.
  Regenerate it after changing the script: `node scripts/gen-scene.mjs hooks/scene.ts`.
- `hooks/make-colors.js`: Claude Code's palette helper, copied unchanged.

## Using it

Load it for one session with `claude --plugin-dir claude-mods/cybernetrix-dark`.
